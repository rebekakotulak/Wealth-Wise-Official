## 🧾 What Is Wealth Wise

Wealth Wise is a web-based personal finance / budgeting tool designed to help you track income and expenses, analyze spending habits, and set savings goals.  

We built this because, as students studying abroad, we needed a smarter way to manage our own finances. At first, we used simple **Excel spreadsheets** to record transactions. Over time, we realized we could turn that into something more powerful and interactive — so Wealth Wise was born.  

This project not only helps us stay on top of our budgets but also showcases our ability to transform everyday problems into real web applications.

---

## ⚙️ Key Features

- Add transactions: **Income** & **Expense**, with category tags (e.g. Salary, Groceries, Rent, Utilities, Transportation, etc.)  
- Filter and view by **Year / Month**  
- **Export to Excel** & **Import from Excel**  
- Dynamic **charts & analysis** — visualize your categories, income vs expenses  
- **Budget calculator** / savings goal planner  
- Summary panels: total income, total expenses, balance, goal progress  
- Transaction table: sortable, filterable, deletable entries
